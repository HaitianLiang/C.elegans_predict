# Reported results

This file records the principal numerical results from the current project analyses. These values are **reported project results**, not synthetic-demo benchmarks and not automatically regenerated by every public-code run.

## 1. Mother-specific analysis

### Data scale

- 4,056 mother-event observations.
- 20 mother-division types.
- Independent 70% train / 30% held-out split within each mother.
- 120 final equations.
- Fixed-alpha Lasso Top-40 candidate pool.
- Greedy ranking retained to at most 15 terms.
- Final equation selected by training-set WAIC; Top-5/8/12/15 retained for structural profiles.

### Half-equation structure

- Weighted-adjacency terms: approximately **70.8%** of selected terms across the 60 final half equations.
- Weighted-adjacency standardized contribution: approximately **62.0%** using $|\beta_j|\,\mathrm{SD}(\phi_j)$.

Frequently reused Top-15 terms include:

|---|---:|
| $\langle z_j^2\rangle_w$ | 19/20 |

| $\langle y_j^2\rangle_w$ | 16/20 |
| $\langle z_j^3\rangle_w$ | 16/20 |
| $\langle(z_mz_j)^3\rangle_w$ | 16/20 |

### Residual layer

Reported standardized half residual model:

$$
\epsilon_{i,m,a}/\sigma_{m,a}\sim t_{13}(0,1.08),
\qquad
\sigma_{m,a}=\mathrm{RMSE}_{\mathrm{train}}(m,a).
$$

Reported standardized residual correlations:

- $\rho_{xy}\approx0.026$;
- $\rho_{xz}\approx0.082$;
- $\rho_{yz}\approx-0.001$.

### Continuous 3D axes

- Median true mother axial strength: **0.955**.
- Minimum reported mother axial strength: approximately **0.864**.
- Overall median mother-level event deviation from its own true dominant axis: approximately **7.84°**.
- Held-out events: **1,224**.
- Event-level true/predicted axis-angle median: **7.44°**.
- Event-level axis-angle IQR: **4.66°–11.38°**.
- 68.7% within 10°; 86.6% within 15°; 94.4% within 20°.
- Predicted/true division-length ratio median: **0.997**.
- Length-ratio IQR: **0.927–1.073**.
- 90.5% of length ratios in $[0.8,1.2]$.
- Mother-level held-out dominant-axis true/predicted angle median: **1.39°**.
- Maximum reported mother-level dominant-axis angle: **5.08°**.
- 19/20 mothers below 5°.
- Held-out true/predicted axial-strength medians: **0.955 / 0.991**.
- True/predicted event deviation from the respective dominant axis: median across mothers approximately **7.68° / 3.23°**.

Interpretation: the model recovers typical mother-specific division axes but underestimates event-to-event directional dispersion.
